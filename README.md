# AoS Chat

A lightweight Ace of Spades chat and spectator client for desktop, Android and iOS.

## Features

- Browse and join public Ace of Spades 0.75 servers.
- Automatically joins as a spectator; team gameplay is inaccessible.
- Fullscreen server chat designed for phones.
- Optional free-camera and player-spectating view.
- Player list with double-tap/double-click spectating.
- Minimal settings: name, camera FOV, sensitivity and UI accent color.
- Builds for Windows, Linux, macOS, Android and unsigned iOS.

AoS Chat retains the compatible networking, map and spectator-rendering internals from its GPL-licensed predecessor while presenting a purpose-built chat application UI.

## iOS

The generated IPA is unsigned. Install it with AltStore, Sideloadly or TrollStore, or re-sign it with your own Apple developer certificate.
