EMOJI FONT SETUP INSTRUCTIONS
==============================

To enable emoji support in the game, you need to download an emoji font file.

RECOMMENDED: Symbola font (monochrome, works great with retro style)
Download from: https://www.symbolafont.net/ or https://fonts.google.com/noto/specimen/Noto+Sans+Symbols+2

ALTERNATIVE: Noto Color Emoji (if you want color emojis, though they will render monochrome in this game)
Download from: https://github.com/googlefonts/noto-emoji/raw/main/fonts/NotoColorEmoji.ttf

STEPS:
1. Download one of the fonts above
2. Rename it to "emoji.ttf"
3. Place it in this directory: resources/fonts/emoji.ttf
4. Rebuild and run the game

The game will work fine without this file - emojis will simply not display until you add it.
